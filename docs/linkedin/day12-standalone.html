THE TWO BRACKETS
corrected  −2·[ ω·ln η + (ω−1)(1−η) ]
old        −2·ω·ln η + (ω−1)(1−η)
One pair of brackets. It shipped in v2.0 and was found by adversarial review of the PR that would have made it reachable.
Two coupled defects, one hiding the other — and the hidden one under-sized the valve by 19 % wherever it applied.
First: an omitted back-pressure defaulted to zero — a perfect vacuum, not a conservative simplification. η = 0 is always below η_c, so the choked branch fired unconditionally and the subcritical equation was dead code for years. Second, inside that dead code: Leung’s bracket was mis-typed, the −2 multiplying only the log term. The red curve is what that produced — at η_c it returns 734 against the choked 591. Flux above choked flux is impossible — choked flow is the maximum — and a flux that is too high divides into an area that is too small. Fixing the default alone would have made this the default path, so both shipped in one PR. The continuity test now pins it: at η = η_c the subcritical form must reproduce the choked value — to within the accuracy of the η_c correlation itself, which is 0.015 % here. That residual is Eq. C.15 approximating a transcendental equation, not the flux formula wobbling.
