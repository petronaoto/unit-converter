Since c ∝ √Z, dropping Z inflates the answer by exactly 1/√Z — so the error peaks where Z bottoms out, at 7.67 % around 2,250 psi, and falls away on both sides: 1.2 % at 200 psi and back to 3.1 % by 4,000 psi.
“Ideal gas gets worse the higher you go” is therefore only half right, and the useful half is narrower: it is worst in the Z-minimum band — for a 0.65-gravity gas at 150 °F that is roughly 1,500–3,000 psi, which is ordinary transmission and gas-processing territory. Note also that the red line is flat: at fixed temperature the ideal-gas c has no pressure dependence at all, so every bit of the shape is Z. It goes into a Mach number — flare headers, blowdown lines, relief tailpipes. The honest boundary: c = √(kZRT/M) is a first-order real-gas correction. It carries Z but not Z’s pressure and temperature derivatives, so it is enough to prove that ignoring Z at 2,000 psi is a several-per-cent error — and not a substitute for an equation of state.
