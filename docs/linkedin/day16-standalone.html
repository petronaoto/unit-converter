Run the directory, not a list. The one excluded file is the only one needing numpy and matplotlib; it gets its own job.
THE REAL FIX — A TEST

Reads ci.yml, globs tests/test_*.py, fails with the filenames if any file is unreachable from the workflow. The suite now tests its own execution.
