Every hydraulic check passes. The regime map says Churn / Slug.

ΔP is a number. Regime is a behaviour, and it is the one that wakes the control room: slugging is a separator-level, pipe-support and control-valve-cycling problem. No pressure-drop figure predicts it — ΔP is an average, and slugging is the variance.

What decides which chart you may even read is geometry:

θ = asin(Δz / L)

At |θ| ≥ 30° the physics is vertical, so the tool plots a Hewitt & Roberts type map — volumetric fluxes j_G vs j_L, in m/s. Below 30°, a Baker type map — mass fluxes G_G vs G_L, in kg/s·m². Not the same chart with the lines moved. The axes change.

Which makes the gate a hard edge. On this line, L = 100 m:

Δz = 50.000 m — θ = 30.0000° — vertical map — Churn / Slug Flow
Δz = 49.999 m — θ = 29.9993° — horizontal map — Slug Flow

One millimetre. And across it j_G = 0.5139 m/s and j_L = 0.5002 m/s do not move — not rounded to the same value, bit-identical. The flow did not change. The chart chosen to describe it did.

The honest part: this tool's region boundaries are simplified piecewise-linear approximations of Hewitt & Roberts (1969) and Baker (1954). Qualitative orientation, not a transition criterion — do not size a slug catcher off them. The inclination gate is the transferable part, and it holds whatever the boundaries look like.

I put the map in because a green ΔP result reads like an answer. It is one answer.

「どのチャートを読んでよいか」を決めているのは幾何です。

θ = asin(Δz / L)

|θ| ≥ 30° なら物理は垂直流。ツールは Hewitt & Roberts 型（体積流束 j_G 対 j_L、m/s）を描きます。30° 未満なら Baker 型（質量流束 G_G 対 G_L、kg/s·m²）。同じチャートの線が動くのではありません。軸そのものが変わります。

Δz = 50.000 m — θ = 30.0000° — 垂直マップ — Churn / Slug Flow
Δz = 49.999 m — θ = 29.9993° — 水平マップ — Slug Flow

1 ミリ。その 1 ミリを跨いでも j_G = 0.5139 m/s、j_L = 0.5002 m/s は動きません。丸めて同じ、ではなく完全に同一です。流れは変わっていない。変わったのは、それを記述するチャートのほうです。
